# 古树迁移方案联合审查台

本项目面向城市绿化技术审查人员、树木养护专业人员和迁移方案编制人员。系统以单株古树迁移个案为核心，将草稿资料、技术规则校验、树木养护与施工协调双专业会审、整改版本、复核批准和审计档案串成可追溯闭环，并防止同一古树编号重复建档。

服务使用 Go 标准库实现单进程 HTTP 服务，浏览器工作台由服务直接提供，无外部系统或前端构建工具依赖。业务数据保存在本地 JSON 快照中，并通过临时文件同步和原子替换保证写入可恢复。每次状态变更使用 `revision` 进行乐观并发控制，使用 `request_id` 保证重试幂等。

工作台左侧审查队列支持按状态、古树编号、树种和迁出或迁入位置组合筛选，并可按更新时间、施工窗口或古树编号稳定分页。个案详情保留每次规则校验批次及结论变化；会审席位可一次提交多个问题；整改工作区要求逐条响应，记录附件元数据和字段到规则的影响链。批准前展示核验清单，批准摘要覆盖最终方案、规则结果、会审与整改内容，后续读取会重新计算并显示验真状态。责任审计时间线记录操作主体、状态变化、`revision` 和缩略后的 `request_id`。

## 环境要求

- Go 1.22 或更高版本
- 可写的数据目录

## 构建

```bash
go build ./cmd/server
```

## 运行

默认监听高位回环地址 `127.0.0.1:19081`：

```bash
go run ./cmd/server
```

可通过参数指定其他回环地址和快照路径：

```bash
go run ./cmd/server -addr=127.0.0.1:19181 -data=data/migration-cases.json
```

也可设置 `PORT` 为端口号，服务将监听 `127.0.0.1:<PORT>`。`-addr` 的显式值优先于 `PORT`。服务拒绝非回环地址和特权端口。

启动后访问 `http://127.0.0.1:19081/` 使用浏览器工作台。健康检查地址为 `GET /healthz`。

## 测试

运行全部单元测试和 HTTP 边界测试：

```bash
go test ./...
```

运行会自行结束的真实 HTTP 冒烟流程：

```bash
go run ./cmd/server -selftest -addr=127.0.0.1:19081
```

自检会在指定地址实际启动服务，通过公开 API 依次完成建稿、规则校验、联合会审、双席位意见、整改版本和批准归档，确认最终状态为 `approved` 后关闭服务。自检使用临时快照，不改写生产数据。

## 业务状态

正常流程依次经过 `draft`、`validated`、`under_review`、`revision_required`、`resubmitted` 和 `approved`。已批准个案不可继续修改；存在阻断性规则结果、未完成专业席位或未解决问题时，系统拒绝推进到不符合条件的状态。

## 数据与恢复

默认快照为 `data/migration-cases.json`，其中包含迁移个案、`request_id` 操作结果和审计事件。服务启动时会验证聚合状态、时间线、操作结果和审计引用关系；快照损坏或不一致时会明确报错并停止启动，避免在不完整数据上继续处理。
